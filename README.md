# IA Text Generator Pro

Sistema de geração de texto educacional criado automaticamente pelo HTML.

## Recursos

- 9 modos de pensamento visíveis
- Prefixos estruturados no TXT
- Workflows com workflow_dispatch
- Pasta training_input com matérias escolares e códigos Python
- Pasta text_output para saída
- Feedback loop em memory
- Treino simples em train.py

## Importante

Este repositório não contém 1,2 bilhão de parâmetros reais.
Ele cria uma arquitetura leve e pronta para integrar um modelo externo maior.

## Como usar

1. No GitHub, abra Actions.
2. Selecione Generate Text.
3. Clique em Run workflow.
4. Preencha prompt, matéria, formato, nível e modo.

Ou use o HTML para disparar os workflows via API.
